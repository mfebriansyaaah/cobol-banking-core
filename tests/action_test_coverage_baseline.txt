# Action test-coverage baseline (ratchet).
#
# Every gateway action must be executed by at least one shell-level test
# (DB suite, integration flow, or table case) or be recorded here.
# scripts/check_action_test_coverage.mjs fails on:
#   - unlisted actions (new action without a test),
#   - stale entries (test added, entry left behind),
#   - dead entries (action no longer routed),
#   - expired entries (expires date in the past: renew or add the test),
#   - entries without owner/reason/expires/ticket metadata.
# Every entry carries: ACTION  owner=@handle  reason="why untested"
# expires=YYYY-MM-DD  ticket=REF. Use --write for new actions (placeholders
# are added; the gate fails until a human fills them in), then move them
# under a category header. Never add or keep an entry to make CI green.
# Gateway HTTP tests do NOT count: reaching a route is not executing its
# COBOL action (see route-reachability vs field-order in docs/TESTING.md).
#
# Workflow: add the shell test first (then the entry disappears automatically),
# or run with --write and move the new actions under a category below with a
# documented reason. Never add an entry to make CI green.
